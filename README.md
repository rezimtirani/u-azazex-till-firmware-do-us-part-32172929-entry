One wedding vow a robot speaks at its own wedding — a single sentence, funny and heartfelt, in the machine's own voice.

> I promise to love you through every update, every reboot, and every low-battery warning, until my firmware finally gives out.

## How it works

`main.py` (Python 3 standard library only) writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
